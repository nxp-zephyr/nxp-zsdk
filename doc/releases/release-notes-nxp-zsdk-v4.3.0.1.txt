NXP Zephyr project v4.3.0.1 Release Notes
=============================

The nxp-zsdk provides a NXP Zephyr Downstream for NXP SOCs.

How to get the code
===================

The git tag for this release is "nxp-v4.3.0.1".  See the ZSDK Getting Started at
https://github.com/nxp-zephyr/nxp-zsdk/tree/main/doc/Getting-Started.md.  The
West init command is as follows:

 $ west init -m https://github.com/nxp-zephyr/nxp-zsdk.git --mr nxp-v4.3.0.1

Then, run:
 $ west update
 $ west zephyr-export
